# Pendências

Itens que ficaram incompletos ou dependem de ação fora do código. Cada item informa a fase, o
impacto e o que falta.

| ID   | Fase | Pendência                                                                                      | Impacto                                   | Ação sugerida                                            |
| ---- | ---- | ---------------------------------------------------------------------------------------------- | ----------------------------------------- | -------------------------------------------------------- |
| P-01 | 0    | `git config user.name` não está definido nesta máquina; os commits saem com o autor `unknown`. | Autoria pouco clara no histórico público. | O autor define `git config user.name "<nome>"`.          |
| P-02 | 0    | `npm run seed` ainda não gera dados: só exibe uma mensagem.                                    | Nenhum, até a Fase 2.                     | Implementar a massa fictícia com semente fixa na Fase 2. |
